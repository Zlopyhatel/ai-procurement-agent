# Smart Procurement Engine (Умный подбор канцтоваров)

B2B-система автоматизации закупок канцтоваров. Продукт находится в процессе миграции на микросервисную архитектуру.

## 🛠️ Стек технологий
* **Backend:** Python 3.12, SQLAlchemy 2.0+
* **Frontend / UI:** Streamlit
* **Database:** SQLite (локальный файл)
* **ИИ-составляющая:** Локальные LLM-агенты через Ollama

## 🔄 Архитектурные контуры (База данных)

База данных реализована на SQLite в файле `data/procurement_orders.db` и состоит из 8 таблиц strictly в единственном числе (Singular):

1. **Контур клиента:**
   * `client` — профили B2B-контрагентов.
   * `client_item` — позиции из внутренних заказов клиентов.
   * `procurement_order` — входящие заказы на закупку.
2. **Контур ИИ:**
   * `item_mapping` — результаты сопоставления позиций клиента с каталогом поставщиков (`confidence_score`).
   * `best_prices_list` — финальные оптимальные предложения.
3. **Контур продавцов (Retailers):**
   * `retailer` — справочник поставщиков (Комус, Атташе).
   * `retailer_item` — универсальный каталог товаров (уникальность по `retailer_sku`).
   * `retailer_pricelist` — история изменения цен, привязанная к дате.

## 🏃 Запуск и разработка

### 1. Точка входа для запуска UI:
```bash
streamlit run src/app.py
```
*Запуск должен производиться строго из корня проекта, чтобы относительные пути внутри папки `src/` корректно находили директорию `data/`.*

### 2. Наполнение справочников:
Скрипт `src/generate_mock_data.py` используется для верификации локальной схемы данных и первичного наполнения таблиц контура продавцов.
```bash
python src/generate_mock_data.py
```
